## Welcome! 👋

T# QR Code Component

A responsive QR code card built with semantic HTML and CSS. This project was developed as part of a [Frontend Mentor](https://www.frontendmentor.io) challenge.

![QR Code Component preview](./preview.jpg)

## Live Demo

* [View live website](https://felipesbelphman-web.github.io/qr-code-component/)
* [View source code](https://github.com/felipesbelphman-web/qr-code-component)

## Overview

The goal of this challenge was to recreate a QR code component as closely as possible to the provided design while keeping the layout responsive across desktop and mobile devices.

## Built With

* Semantic HTML5
* CSS3
* Flexbox
* Responsive design
* Google Fonts

## What I Learned

During this project, I practiced:

* Structuring content with semantic HTML elements
* Centering components with Flexbox
* Using the CSS box model with padding, width and `box-sizing`
* Creating responsive layouts with `max-width`
* Applying typography, colors, spacing and border radius
* Organizing styles with reusable CSS classes
